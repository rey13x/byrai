Buat Bookmark Tersembunyi

Fitur ini buat menyamarkan link terkunci jadi bookmark biasa. Misalnya, link rahasia Anda bisa kelihatan seperti bookmark Gmail. Orang yang melihat bilah bookmark jadi tidak langsung tahu ada link yang dikunci kata sandi.

Hasilnya adalah dua bookmark:

  • Bookmark samaran: bookmark yang kelihatan biasa, tapi menyimpan link rahasia Anda.
  • Bookmark dekripsi: bookmark yang jadi “kunci” untuk membuka bookmark samaran.

Cara buka link rahasia: klik bookmark samaran dulu, lalu klik bookmark dekripsi. Kalau urutannya benar, Jaga Link akan meminta kata sandi. Masukkan kata sandi yang tadi Anda buat untuk membuka link asli.

Bookmark dekripsi cukup dibuat sekali dan bisa dipakai untuk semua bookmark samaran Anda.

Gampang, ikuti langkah ini:

  1. Buat link terkunci dulu lewat Jaga Link. Setelah jadi, salin link hasilnya.
  2. Seret bookmark "Dekripsi" di bawah ini ke bilah bookmark browser. Ini bookmark kuncinya.
    • Kalau tidak sedang membuka link samaran, bookmark ini akan membuka gmail.com. Alamatnya bisa diganti lewat opsi "lanjutan".
    lanjutan

  3. Supaya makin tidak mencolok, ubah nama bookmark dekripsi jadi nama biasa, misalnya "Gmail".
  4. Tempel link hasil tadi ke kolom URL tersembunyi. Isi nama bookmark dan alamat samaran yang mau ditampilkan.
    • Belum punya alamat samaran? Klik Gunakan link samaran acak.
  5. Klik Buat bookmark samaran, lalu seret hasilnya ke bilah bookmark.
